# 정답

학습 단계마다 통과하는 회로를 하나씩 찍어 둔 것이다.
**막혔을 때만 보는 게 낫다.** 답을 보고 나면 그 단계는 다시 안 풀린다.

`H` 를 눌러 힌트를 먼저 보고, 그래도 안 되면 여기를 본다.

정답은 하나가 아니다. 여기 있는 건 되는 것 중 하나일 뿐이고,
네가 짠 게 표대로 돌면 그것도 정답이다.

## 다시 뽑기

```
cd ..
mkdir -p 정답
./semtle --answers
```

`.ppm` 으로 나오니 `magick` 같은 걸로 `.png` 로 바꾸면 된다.

이 그림들은 검사(29번)가 쓰는 것과 **같은 코드**로 짓는다.
따로 두면 어느 한쪽이 낡아서, 정답이라고 올려놓은 게 실제로는
통과 못 하는 일이 생긴다.
