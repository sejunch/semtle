# 셈틀

배선과 게이트만으로 회로를 조합하는 판.

이름은 **'컴퓨터' 를 순우리말로 쓰던 말**에서 왔다 — 셈(계산) + 틀(기계).
NAND 하나로 시작해서 계산기까지 쌓아 올리는 판이라 그대로 가져다 썼다.

부품(스위치·전구·게이트)을 판에 끌어다 놓고, 출력 포트에서 입력 포트로 선을 잇는다.
매 틱마다 게이트가 입력을 보고 출력을 정한다. 스위치를 켜면 신호가 선을 타고 흘러
전구가 켜진다. 이걸 쌓으면 반가산기, 기억(래치), 카운터, 끝까지 가면 계산기가 된다.

모래의 배선·게이트를 격자에서 떼어 내 노드-그래프로 다시 만든 것이다.

## 실행

```
make          # 빌드
./semtle      # 실행
./semtle --test   # 화면 없이 회로 논리만 검사
```

SDL2 하나만 있으면 된다. 글자는 `stb_truetype.h` 로 직접 그려서 SDL_ttf 를 안 깐다.

## 두 갈래

첫 화면에서 고른다. `Esc` 로 언제든 여기 돌아온다.

**학습** — 스위치와 전구부터 시작해 **서른 단계**를 오른다. 컴퓨터를 만들고, 화면에 그림까지 찍는다. 단계마다 짧은 설명과 진리표가 있고,
회로를 짜서 `Enter` 로 채점한다. 통과하면 그게 부품이 되어 다음 단계에서 쓰인다.

**샌드박스** — 빈 판. 전부 열려 있다.

**저장본이 따로다.** 문제 풀다 샌드박스로 가도 만들던 회로가 그대로 있다.

### 단계 고르기

학습을 고르면 **단계 목록**이 먼저 뜬다. 서른 단계가 부로 묶여 있고, 부마다
난이도(다섯 칸)와 한 줄 소개가 붙는다. 통과한 단계는 초록 네모, 지금 단계는 파란 줄,
아직 안 열린 것은 흐리다. **통과한 데까지만** 눌러서 갈 수 있다.

단계 안에서도 설명판 맨 위에 그 부의 이름·난이도가 뜬다. 그 머리말을 누르면 목록으로
돌아간다. 창이 좁으면 소개 줄부터, 더 좁으면 머리말째로 접힌다 — 목록에 가면 다 있다.

난이도는 **부마다 하나**다. 같은 부 안의 단계들은 어차피 비슷한 수준이라 따로 매길 게 없다.

2·3부는 붙박이 게이트를 **써 보며 익히는** 단계라 통과해도 부품으로 안 남는다.
나머지는 통과하면 그 회로가 칩이 되어 뒤 단계에서 쓰인다.

### 28단계 — 컴퓨터

명령 한 바이트가 **윗 2비트(무엇을) + 아랫 6비트(어떤 수로)** 다.
`1` = 넣기, `2` = 더하기, `0` = 멈춤.

세는상자가 램 주소를 가리키고, 램이 명령을 내놓고, 해독기가 무엇을 할지 정하고,
누산기가 담거나 더한다. 채점할 때 램에 `넣기 20` `더하기 22` `멈춤` 이 들어가고,
클럭을 몇 번 올려서 누산기가 **42** 가 되는지 본다.

### 기억하는 회로는 어떻게 채점하나

진리표로는 못 잰다. 지난 일에 따라 답이 달라지기 때문이다.
그래서 **값을 차례로 넣어 보는 대본**을 쓴다 — "이 값들을 넣고 좀 돌린 뒤,
이 출력이 이 값이어야 한다" 를 여러 칸 늘어놓는다. 틀리면 몇 번째에서
무엇이 틀렸는지 말해 준다.

**SR래치는 처음에 깜빡인다.** NOR 둘이 완전히 대칭이라 동시에 값을 바꾸면
(0,0)과 (1,1)을 오간다. 실제 회로의 준안정 상태와 같은 것이고, 셋이나 리셋을
한 번 눌러 주면 자리를 잡는다. 검사 대본도 먼저 값을 한 번 밀어 넣어 자리를 잡힌다.

**힌트**가 단계마다 하나씩 있다. `H` 를 누르면 판 위에 뜬다. 답을 통째로 알려 주지는 않고,
어디부터 손대면 되는지만 짚어 준다. 글이 자리보다 길면 알아서 접힌다.

채점기는 입력을 **모든 경우로 돌려 보고** 진리표와 맞는지 본다. 틀리면 어느 입력에서
무엇이 몇이었는지 짚어 준다. 핀 이름으로 어느 것이 어느 입력인지 찾으므로,
단계를 시작하면 이름 붙은 핀이 미리 놓여 있다.

**과정을 고치면** 저장된 진도가 엉뚱한 단계를 가리키게 된다. 과정에 번호를 붙여 두고,
번호가 다르면 **진도만 처음으로 되돌리고 얻어 둔 칩은 남긴다.**

## 글자 크기와 창 크기

**`[` 와 `]` 로 글자 크기를 바꾼다.** 80%부터 220%까지. 글자만이 아니라 **판·단추·줄 간격이
다 같이** 커지고 작아진다. 고른 값은 저장되어 다음에도 그대로다.

속으로는 자리·크기 숫자를 전부 '1배일 때 값' 으로 적어 두고 쓸 때 `S()` 로 늘린다.
글자 크기도 마찬가지라, `drawText` 에 넘기는 숫자는 늘 1배 기준이다.

**`Tab` 을 누르면 좌우 판이 사라진다.** 회로가 화면 전체를 쓴다. 큰 회로를 볼 때 쓴다.
판이 어디서 시작하는지는 `canvasL()`·`canvasR()` 하나로만 정하고, 화면↔판 좌표 바꾸는
것도 그걸 쓰므로 판이 사라져도 마우스 자리가 안 어긋난다.

**창을 마음대로 늘리고 줄일 수 있다.** 왼쪽 도구판과 오른쪽 설명판은 너비가 그대로고,
늘어나고 줄어드는 몫은 **가운데 판이 다 가져간다.**

- 설명 글자는 창 높이에 맞춰 정해진다. 작은 창에서도 채점 단추를 안 밀어낸다.
- 부품 목록은 줄 높이가 고정이고, 넘치면 **굴려서** 본다.
  (예전엔 다 들어가게 줄을 좁혔는데, 그러면 칩이 쌓일수록 빽빽해지고
  굴릴 일이 없어져 휠이 안 먹는 것처럼 보였다)
- 제일 작게 줄여도 판이 남도록 최소 크기를 잡아 두었다.

## 조작

- **부품 찾기** — 목록 위 칸에 치거나 `/`. 이름에 든 것만 남는다. `Esc` 로 지우기
- **목록 굴리기** — 목록 위에서 휠, 또는 오른쪽 막대를 잡고 끌기
- **부품 놓기** — 왼쪽에서 부품을 고르고(또는 `1`~`9`) **빈 곳**을 클릭.
  놓기 도구인 채로 **이미 있는 부품을 잡고 끌면 옮겨진다**
- **선 잇기** — 부품의 **출력 포트**를 잡고 끌어서 다른 부품의 **입력 포트**에 놓기
- **손 도구**(`` ` `` 또는 Esc) — 부품 끌어 옮기기, **스위치·입력핀 눌러 켜고 끄기**
- **핀 이름 고치기** — 핀을 고르거나 핀 위에 커서를 두고 `F2`
- **포트 알아보기** — 포트에 마우스 올리면 말풍선. **이름 · 몇 비트 · 지금 값**이 뜬다
- **여럿 고르기** — 손 도구로 빈 판을 드래그. 고른 것 하나를 끌면 통째로 따라온다
- **하나씩 고르기** — `Shift+클릭`. 이미 고른 것을 다시 누르면 빠진다.
  `Shift+드래그` 는 이미 고른 것에 **더한다**
- **돌리기** — `R` (`Shift+R` 은 반대). 고른 부품의 입출력 방향이 90도씩 돈다
- **복사 / 붙여넣기** — `Ctrl+C` 로 담고 `Ctrl+V` 로 커서 자리에 꺼낸다. 안의 선까지 따라온다
- **바로 복제** — `Ctrl+D`. 담아 두지 않고 그 자리 옆에 하나 더
- **묶기** — 고른 뒤 `G`(또는 "게이트로 묶기") → 이름 입력
- **칩 고치기** — 칩 상자를 더블클릭, 또는 목록 줄의 연필 단추. `Esc` 로 나오면 반영
- **화면 이동** — 가운데 버튼 드래그, 또는 휠(`Shift+휠` 은 가로)
- **확대·축소** — `Ctrl+휠`, 또는 `-` / `=`. `F` 는 다 보이게 맞춤, `0` 은 100%
- **처음 자리로** — `스페이스`. 화면을 판의 (0,0) 으로 되돌린다 (배율은 그대로)
- **힌트** — 학습 모드에서 `H` (또는 "힌트" 단추). 판 위에 뜬다
- **판 숨기기** — `Tab`. 좌우 판이 사라지고 회로가 화면 전체를 쓴다
- **선 폭 바꾸기** — 핀·묶음·풀음·스위치묶음·화면을 고르고 `W` (`Shift+W` 는 줄이기). 1~16비트
- **화면 줄 수** — 화면을 고르고 `E` (`Shift+E` 는 줄이기). 1~16줄
- **비트 켜고 끄기** — 스위치묶음이나 **폭 있는 입력핀**의 칸을 클릭.
  아래에 값이 수로 뜬다 (1비트 핀은 예전처럼 통째로 뒤집힌다)
- **묶음·풀음 접기** — 두 번 누르거나 `Q`. 자리를 덜 먹는다 (3비트부터)
- **클럭 빠르기** — 클럭을 고르고 `,` `.`
- **글자 크기** — `[` / `]`
- **되돌리기** — `Ctrl+Z` (`Ctrl+Shift+Z` 또는 `Ctrl+Y` 는 다시 하기)
- **내보내기 / 가져오기** — `Ctrl+S` / `Ctrl+O`
- **지우기** — 고르고 `Del`
- **선 끊기** — 선 위에서 **우클릭**. 눌러서 고른 뒤 `Del` 도 된다
- **손 도구로** — 빈 곳에서 우클릭 (한 번 더 누르면 고른 것도 놓는다)
- **멈춤** — `P`
- **첫 화면으로** — `Esc`. **나갈지 한 번 묻는다** (Enter 나가기 · Esc 계속하기)
- **조작키 다 보기** — `?` (Shift+/). 판 위에 창이 뜬다. 아무 키나 눌러 닫는다

`?` 창만은 **진짜 픽셀로 잰다.** 다른 것은 다 1배 기준 숫자에 `S()` 를 곱하는데,
글자 배율 2.2배에 창이 작으면 스물세 줄이 어떻게 해도 안 들어간다. 그래서 배율을
따르되 안 맞으면 스스로 줄어들고, 11픽셀보다는 안 작아진다.

`Esc` 는 순서대로 물러난다 — 도구를 고른 상태면 손 도구로, 뭘 골라 뒀으면 놓고,
힌트가 펼쳐져 있으면 접고, 그러고도 남으면 나갈지 묻는다.

폭이 여럿이면 스위치묶음처럼 칸이 생긴다 |
| **출력핀** | 1 | **칩으로 묶었을 때 출력 포트가 된다** |
| AND | 2 | 둘 다 켜져야 켜짐 |
| OR | 2 | 하나만 켜져도 켜짐 |
| NOT | 1 | 뒤집음 |
| XOR | 2 | 둘이 다를 때만 켜짐 |
| NAND | 2 | AND 의 반대 |
| NOR | 2 | OR 의 반대 |
| **클럭** | 0 | 제 박자로 혼자 켜졌다 꺼졌다 한다. `,` `.` 로 빠르기 조절 |
| **묶음** | N | 가는 선 N개를 굵은 선 하나로 (0번이 제일 아랫자리) |
| **풀음** | 1 | 굵은 선 하나를 가는 선 N개로 |
| **램** | 4 | 주소·데이터·쓰기·클럭 → 데이터. 256칸 × 8비트 |
| **스위치묶음** | 0 | 스위치 n개를 한 부품으로. 칸을 눌러 비트를 켜고 끈다 |
| **화면** | n | n개의 m비트를 n줄 × m칸 점으로 (n, m ≤ 16) |

여기에 **직접 묶은 커스텀 게이트**가 왼쪽 목록에 계속 붙는다(아래 참고).

## 굵은 선 (여러 비트)

선 하나가 **1비트가 아니라 여러 비트**를 나를 수 있다. 8비트 버스 하나가 예전의 선
여덟 가닥을 대신한다. 안 그러면 레지스터 둘만 이어도 화면이 선으로 뒤덮인다.

- 포트마다 폭이 있고, **폭이 같아야 이어진다.** 굵은 선을 가는 구멍에 못 꽂는다
- 굵은 선은 더 두껍고 파랗게 그린다
- **포트 모양도 다르다** — 한 비트짜리는 동그라미, 굵은 쪽은 가로줄이 든 네모.
  꽂기 전에 눈으로 맞는지 알 수 있다
- **묶음**으로 가는 선 여럿을 굵은 선 하나로, **풀음**으로 도로 푼다
- 묶음·풀음은 가닥이 여덟이면 세로로 길어진다. **다 이은 뒤에는 접어 두면 된다** —
  두 번 누르거나 `Q`. 상자만 작아지고 **이어 둔 선은 그대로**다.
  다시 펴야 가닥별로 새로 잇기 편하다
- 핀 폭을 바꾸면 칩 포트 폭도 따라 바뀐다. 안 맞게 된 선은 끊고 몇 개인지 알려 준다

## 한 틱 지연이 핵심이다

모든 부품이 **이번 틱 입력을 먼저 다 읽고, 그 다음 한꺼번에 출력을 바꾼다.**

이 한 틱 지연이 없으면 되먹임 고리(출력이 돌고 돌아 자기 입력으로 오는 것)가
한 틱 안에 무한히 돌아 버린다. 지연이 있으면 실제 회로처럼 값이 한 칸씩 전해진다.

덕분에 **NOR 두 개를 서로 물리면 값을 기억하는 래치**가 된다. 셋 신호를 잠깐 주면
켜진 채로 남고, 리셋 신호를 잠깐 주면 꺼진 채로 남는다. 기억 소자가 게이트 두 개에서
저절로 나온다. 조합 회로(입력만으로 정해짐)와 순차 회로(과거를 기억함)의 경계가 여기다.

## 커스텀 게이트

만든 회로를 상자 하나로 묶어 부품처럼 다시 쓸 수 있다. 반가산기를 묶어 "반가산"
상자로 만들고, 그걸 여러 개 이어 전가산기를 만들고… 쌓으면 계산기까지 간다.

**묶는 법:** 손 도구로 빈 판을 드래그해 부품들을 고르고 `G`. 안의 **입력핀이 입력 포트,
출력핀이 출력 포트**가 된다(위→아래 순서대로). 이름을 치면 왼쪽 목록에 새 부품으로 뜬다.

### 핀과 포트 이름

포트가 될 자리에는 **입력핀·출력핀**을 놓는다. 핀에는 이름이 붙는다 — 놓을 때
`입력1`·`출력1` 처럼 자동으로 붙고, **`F2` 로 고칠 수 있다.**
그 이름이 그대로 칩의 포트 이름이 된다.

포트에 **마우스를 올리면 말풍선이 뜬다** — `합 · 8비트 · 42` 처럼 이름과 폭과 지금 값을
같이 보여 준다. 어느 점이 '합'이고 어느 점이 '올림'인지, 몇 비트짜리인지 헷갈릴 일이 없다.

핀만 포트가 되므로 **칩 안에 스위치를 묻어 둘 수 있다.** 켜 둔 채로 묶으면 그 칩
안에서 늘 1인 상수가 된다. (예전에는 안의 스위치가 전부 입력 포트로 끌려나갔다.)

묶기 전에 회로를 돌려 보려면 **입력핀을 그냥 눌러서** 켜면 된다. 스위치처럼 토글된다.

**속으로 어떻게 도나:** 상자는 안에 원래 회로를 그대로 품는다. 매 틱마다
바깥 입력을 안쪽 입력핀에 꽂고 → 안쪽을 한 틱 돌리고 → 안쪽 출력핀 값을 바깥 출력으로 뺀다.

- 상자마다 **속 회로를 따로 복사**해 갖는다. 같은 상자를 둘 놓아도 서로 값이 안 섞인다.
- **상자 안에 상자**도 된다. 안쪽도 똑같이 SubSim 이라 같은 코드로 재귀해서 돈다.
- 안에 래치가 있으면 **기억하는 상자**가 된다.

한 부품이 출력을 여럿 가질 수 있게 만든 것이 이걸 위해서다(반가산기 = 합 + 자리올림).

### 고치기

**칩 상자를 더블클릭**하거나 목록 줄의 **연필 단추**를 누르면 그 칩 속으로 들어간다.
판 위에 설계도가 올라오고, 위에 파란 띠가 둘린다. 고친 뒤 `Esc` 로 나오면 반영된다.

**이미 놓은 상자도 전부 같이 바뀐다.** 판에 놓인 것도, 다른 칩 속에 들어 있는 것도.
`full_adder` 를 고치면 그걸 쓴 4비트 가산기까지 자동으로 고쳐진다.

- **칩 안의 칩도 열 수 있다.** 더 들어가면 띠에 `겉칩 > 속칩` 하고 길이 쌓인다.
- **자기 안에 자기는 못 넣는다.** 고치는 중인 칩은 목록에서 잠기고, 지우기도 막힌다.
- **포트를 줄이면** 없어진 포트에 걸려 있던 **선만 끊고** 나머지는 그대로 둔다.
  몇 개 끊겼는지 알려 준다.
- 고치는 동안에는 자동 저장을 미룬다 (판에 올라온 게 설계도라서). 나올 때 저장된다.

### 지우기

목록의 커스텀 게이트 줄 오른쪽 `×` 를 누르면 지워진다. 단 **쓰는 중이면 못 지운다.**
판에 놓여 있거나 다른 게이트 속에 들어 있으면 "3군데서 쓰는 중이라 못 지움" 하고 막는다.
반가산으로 전가산을 만들었으면 전가산을 먼저 지워야 반가산이 자유로워진다.

속으로는 지운 칩의 자리를 **비우지 않고 표시만 꺼 둔다.** `chipId` 가 `chips[]` 의
자리라서, 진짜로 빼면 뒤엣것들의 번호가 밀려 이미 놓인 상자가 엉뚱한 걸 가리키게 된다.

### 단계에서 받은 부품은 되살아난다

학습에서 통과 상품으로 받은 칩은 뒷 단계의 재료다. 그걸 지우고 저장하면
다음 단계를 영영 못 깨게 되므로 두 겹으로 막는다.

- **막기** — 학습 모드에선 통과한 단계의 상품 칩에 `×` 가 안 먹는다.
  "'플립플롭' 은 단계에서 받은 부품이라 못 지움" 하고 튕긴다.
- **되살리기** — 학습에 들어갈 때와 단계를 옮길 때, 통과한 단계 중 칩이 없어진 게
  있으면 그 단계의 정답 회로를 다시 지어서 칩으로 굳힌다. 판은 안 건드린다
  (짓기 전에 통째로 떠 놨다가 도로 돌려놓는다). 되살렸으면
  "없어진 부품 2개를 되살렸다" 하고 알려 준다.

이미 지운 채로 저장해 버린 파일도 다음에 학습을 열면 저절로 고쳐진다.

## 되돌리기

`Ctrl+Z` 로 되돌리고 `Ctrl+Shift+Z`(또는 `Ctrl+Y`) 로 다시 한다. 60단계까지.

바뀌기 **직전 상태를 통째로 찍어** 쌓아 둔다. 회로가 작아서, 무엇이 어떻게 바뀌었는지
일일이 적는 것보다 통째로 찍는 쪽이 훨씬 간단하고 안 틀린다. 칩 설계도까지 같이 찍히므로
**칩을 묶기 전으로도 되돌아간다.**

**스위치를 껐다 켜는 건 안 쌓는다.** 그건 회로를 *돌려 보는* 것이지 *고치는* 게 아니다.
그것까지 쌓으면 몇 번 만져 보는 사이에 진짜 고친 기록이 60칸 밖으로 밀려 나간다.
(저장은 된다 — 되돌리기 더미에만 안 쌓는다.)

되돌린 뒤에는 골라 둔 것과 끌던 것을 놓는다. 그것들은 부품을 **번호로** 가리키는데,
되돌리면 그 번호가 딴 걸 가리킬 수 있기 때문이다.

## 저장

**알아서 저장된다.** 저장 버튼이 없다. 뭘 바꾸고 잠깐(¾초) 가만있으면 조용히 쓰고,
오른위에 "저장됨" 이 잠깐 뜬다. 창을 닫을 때도 한 번 더 쓴다.
다음에 켜면 **만든 커스텀 게이트와 판이 하던 그대로** 돌아온다.

파일은 `~/.local/share/semtle/` 안에 셋:

| 파일 | 든 것 |
|------|-------|
| `chips.txt` | **만든 칩 전부** — 모드와 상관없이 같이 쓴다 |
| `state.txt` | 샌드박스 판 |
| `learn.txt` | 학습 판 + 진도 |

**칩은 같이 쓰고 판은 따로다.** 학습에서 딴 칩을 샌드박스에서 바로 꺼내 쓸 수 있고,
판은 서로 안 섞인다. 사람이 읽을 수 있는 글이다.
이름이 `논리` 이던 시절 파일도 그대로 읽힌다(머리말만 다르다).

내보내기(`Ctrl+S`)는 칩까지 한 파일에 담는다 — 남한테 주면 그대로 돈다.
`SEMTLE_SAVE` 로 딴 자리를 지정할 수 있다.

### 내보내기 · 가져오기

`Ctrl+S` 는 지금 것을 **딴 파일로 한 부 뽑고**, `Ctrl+O` 는 그런 파일을 **가져온다.**
자동 저장은 그대로 돌아간다 — 내보내기는 자동 저장 파일을 안 건드리고,
가져오면 그게 지금 것이 되어 다시 자동 저장된다. 가져오기도 `Ctrl+Z` 로 되돌릴 수 있다.

파일 창은 바탕화면에 이미 있는 `zenity`(없으면 `kdialog`)를 잠깐 띄워 쓴다.
SDL2 에는 파일 창이 없다(SDL3 부터 생겼다). 둘 다 없으면 조용히 포기하고 알려 준다.

- **상자 인스턴스의 속 회로는 안 쓴다.** 설계도에서 다시 찍어 내면 되고,
  그래야 파일이 중첩 깊이만큼 부풀지 않는다. 대신 **스위치가 켜졌는지는** 쓴다 —
  스위치만 제자리면 나머지는 몇 틱 돌면 저절로 제 값을 찾는다.
  (칩 속 래치가 기억하던 값은 안 남는다. 껐다 켜면 초기 상태부터다.)
- **지운 부품·칩도 자리째 쓴다.** 선이 부품을 번호로 가리키기 때문에, 빼면 번호가 밀린다.
- 핀 이름은 줄 맨 끝에 쓴다(빈칸이 들어갈 수 있어서). 이름 칸이 없는 **예전 파일도 그대로 읽히고**,
  그때 쓰던 스위치·전구 포트는 **핀으로 자동 변환**된다.
- 임시 파일에 다 쓴 뒤 갈아치운다. 쓰다 죽어도 예전 파일이 안 깨진다.
- 파일이 깨져 있으면 **읽기를 포기하고 하던 것을 그대로 둔다.** 반쯤 읽다 만 상태로 안 만든다.

## 돌리기와 화면

부품마다 방향(`rot`)이 있다. 0이면 출력이 오른쪽, 한 칸 돌 때마다 아래·왼쪽·위로 간다.
입력은 늘 출력의 **맞은편**에 붙는다. 홀수로 돌면 상자의 가로·세로가 바뀌므로,
돌려도 **가운데가 안 움직이게** 자리를 다시 잡아 준다.

선은 양 끝 포트가 **보는 쪽으로 뻗어 나갔다가** 이어진다. 그래서 돌린 부품끼리 이어도
선이 상자를 뚫고 지나가지 않는다. 신호가 왼쪽으로 되돌아가야 할 때(되먹임 고리)
부품을 돌려 놓으면 선이 훨씬 덜 꾸인다.

부품 좌표는 **판 좌표**로 들고 있고, 그릴 때만 화면 좌표로 바꾼다. 마우스는 들어오자마자
판 좌표로 바꾸므로 히트 테스트 코드는 배율을 아예 모른다. 확대는 **커서 밑을 고정한 채**
배율만 바꾼다 — 그래서 확대해도 보던 자리가 안 밀린다.

## 규칙 몇 가지

- **안 이은 입력은 0** 으로 본다.
- **입력 하나엔 선 하나.** 이미 이은 입력에 다시 이으면 앞엣것이 끊기고 갈아탄다.
- 한 출력은 여러 입력에 이어도 된다(부채꼴).
- 스위치의 출력값은 사람이 정한 값 그대로다. 시뮬레이션이 안 건드린다.

## 저장 파일

판과 칩을 텍스트로 쓴다. 먼저 `.tmp` 에 다 쓰고 나서 갈아치우므로, 쓰다 죽어도
예전 파일이 안 깨진다.

**판과 칩은 다른 파일이다.** 판은 모드마다 따로(`state.txt` · `learn.txt`), 칩은
`chips.txt` 하나에 모아 둔다 — 학습에서 얻은 부품을 샌드박스에서도 쓰라고 그렇게 했다.
그래서 **읽을 때 칩을 먼저 읽어야 한다.** 판이 칩을 번호로 가리키기 때문이다.
한동안 모드에 들어갈 때 판만 읽고 칩은 안 읽어서, 만들어 둔 게이트가 통째로
사라졌다. 학습에서만 멀쩡해 보였는데, 그건 상품 칩을 `repairLessonChips` 가
매번 다시 만들어 줘서였다.

없는 칩을 가리키는 상자를 만나면 그 자리만 죽은 채로 두고 넘어간다. 예전엔 파일을
통째로 물렸는데, 그러면 칩 파일 하나 어긋났다고 판이 다 날아간다.

폴더 만들기와 갈아치우기는 `<filesystem>` 으로 한다. 예전엔
`system("mkdir -p ...")` 와 `std::rename` 이었는데 **윈도우에서 둘 다 안 됐다** —
cmd 에는 `mkdir -p` 가 없고, `rename` 은 대상 파일이 이미 있으면 실패한다
(POSIX 는 덮어쓴다). 그래서 처음 저장은 되고 **두 번째부터 조용히 실패**했다.

## 검사

`./semtle --test` 는 화면 없이 회로만 짜서 돌려 본다. 지금 67가지.
글꼴도 같이 읽어 둔다 — 안 그러면 글자 너비가 0 이라 자리 검사가 헛돈다.



- 게이트 진리표 (AND·OR·XOR·NAND·NOR)
- NOT
- **반가산기** (XOR=합, AND=자리올림)
- **NOR 래치** (입력 다 뗀 뒤에도 값을 기억)
- **커스텀 게이트** (묶은 반가산기가 판에서와 똑같이 돎)
- **상자 여럿이 서로 안 섞임** (인스턴스마다 속 회로 따로)
- 선을 끊으면 신호가 안 감
- **쓰는 중인 게이트는 못 지움** (비운 뒤엔 지워짐)
- **다른 게이트 속에 든 것도 지켜짐**
- **지워도 남은 게이트 번호가 안 밀림**
- **복사하면 선까지 따라옴** (원본이랑 상태가 안 섞임)
- **반만 고르면 선은 안 따라옴** (한쪽 끝만 고른 선까지 복제하면 입력에 선이 둘 붙는다)
- **돌려도 논리는 그대로** (포트 자리만 바뀌고, 네 번 돌면 제자리)
- **돌리면 가로세로가 바뀌고 가운데는 그대로**
- **확대·이동 좌표가 안 어긋남** (기준점 고정, 화면↔판 왕복, 배율 한계)
- **채점기가 맞고 틀림을 가린다** (빈 판·틀린 회로·핀 없음까지)
- **통과하면 칩이 되고 판은 남는다** (두 번 눌러도 안 늘어남)
- **단계마다 쓸 부품이 제한된다** (샌드박스는 다 열림)
- **칩은 같이 쓰고 판은 따로다** (학습에서 딴 칩을 샌드박스에서 씀)
- **모드끼리 판이 안 섞인다**
- **학습 단계가 순서대로 풀린다** — 스물일곱 단계를 허락된 부품만으로 실제로 풀어 본다.
  정답이 그 단계의 규칙을 지켰는지도 같이 본다. 한 단계라도 못 풀면 학습 모드가
  거기서 막히므로 이게 제일 중요한 검사다.
- **과정이 바뀌면 진도만 초기화된다** (얻은 칩은 남음)
- **설명판이 작은 창에서도 안 넘친다** (배율 0.8~2.2 × 모든 단계)
- **창 크기가 바뀌어도 자리가 안 어긋난다** (배율 셋 × 크기 셋, 화면↔판 좌표 왕복까지)
- **칩이 많아도 목록이 다 보인다** (배율 0.8~2.2 에서 줄을 좁혀서)
- **단계마다 힌트가 있다** (제일 좁은 창에서 접었을 때 몇 줄이 되는지까지 잰다)
- **글 접기가 자리에 맞춘다** (네 가지 너비에서 안 넘치고 글자도 안 잃는다)
- **나갈까 묻는 창이 제자리에 뜬다**
- **글자 배율이 다 같이 커진다** (글자·판·줄, 한계, 저장까지)
- **Tab 으로 판을 숨기면 넓어진다** (숨긴 상태에서도 좌표가 왕복하는지까지)
- **칩을 고치면 놓인 것도 다 바뀐다** (AND 를 OR 로 바꿔서 확인)
- **칩 속의 칩까지 고침이 내려간다** (속칩을 뒤집으면 겉칩도 뒤집힌다)
- **포트가 줄면 그 선만 끊긴다** (남은 선은 멀쩡한지까지)
- **자기 안에 자기를 못 넣는다** (목록·다시 열기·지우기 다 막힘)
- **목록 찾기가 걸러 준다**
- **휠로 굴리면 줄이 움직인다** (굴리는 코드가 통째로 빠져 있던 적이 있다)
- **굴림 막대가 제자리에 있다** (배율 0.8~2.2 에서 길 안, 끝까지)
- **복사와 붙여넣기가 따로 논다** (복사는 판을 안 건드림)
- **반만 고르면 선은 안 담긴다**
- **지운 상품 칩이 되살아난다** (플립플롭을 지워 레지스터 단계가 막히는 걸 확인하고,
  되살린 뒤 다시 풀리는 데까지 본다)
- **부가 단계를 빠짐없이 나눈다** (겹치거나 빠진 단계가 없는지)
- **조작키 창이 창 안에 들어온다** (배율 넷 × 창 셋. 두 칸이 겹치는지까지)
  화면 검사에서는 **진짜 `?` 키를 눌러서** 연다 — 안에서 깃발만 켜고 보면
  키를 받는 코드가 통째로 빠져도 모른 채 지나간다 (실제로 그랬다)
- **같은 자리에 두 번 저장해도 된다** (윈도우에서 두 번째 저장이 조용히 실패하던 것)
- **만든 게이트가 자동 저장에 남는다** (판과 칩이 다른 파일이라 칩 쪽만 빠질 수 있다)
- **모드에 들어갈 때 칩 파일을 읽는다** (안 읽어서 만든 게이트가 통째로 사라졌다.
  칩 파일이 없어져도 판은 살아남는지까지)
- **단계 목록의 누른 자리가 맞는다** (배율 셋 × 창 셋에서 줄의 위·가운데·아래를 다 눌러 본다.
  그리는 셈과 누르는 셈이 따로라 어긋날 수 있다)
- **묶음·풀음이 값을 실어 나른다** (8비트 값이 그대로 오감)
- **접어도 선이 안 끊긴다** (상자만 작아지고 값·포트는 그대로, 저장도 됨)
- **스위치묶음이 눌린 대로 값을 낸다** (저장까지)
- **폭 있는 입력핀은 칸으로 넣는다** (1비트는 예전처럼)
- **화면이 줄마다 값을 받는다** (줄·칸 수를 바꾸면 포트도 따라감, 16×16 까지)
- **폭이 다르면 안 이어진다**
- **클럭이 제 박자로 뒤집힌다** (빠르기를 바꾸면 횟수도 바뀜)
- **램이 클럭에 맞춰 쓰고 늘 읽는다** (올라가는 순간에만 써짐)
- **폭·클럭·램 속이 저장된다**
- **클럭·묶음·램이 이어서 돈다** — 손으로 값을 꽂지 않고 판에 회로를 짜서
  시뮬레이션만으로 확인한다. CPU 의 뼈대가 실제로 도는지 보는 검사다
- **이름 바꾸기 전 저장본도 읽힌다** (`논리` 머리말 → 다시 쓰면 `셈틀` 로)
- **저장했다 불러오면 그대로** (칩·판·스위치·회전·보기까지)
- **깨진 파일에 안 무너짐** (읽기 실패해도 하던 게 남음)
- **핀 이름이 포트 이름이 됨** (위→아래 순서대로)
- **칩 안 스위치는 상수로 남음** (포트로 안 끌려나감)
- **예전 저장본이 핀으로 바뀜** (스위치·전구 포트를 자동 변환)
- **되돌리기·다시하기** (선·부품이 사라졌다 돌아옴)
- **되돌리면 칩도 사라짐** (묶기 전으로)
- **스냅샷이 원본과 안 얽힘** (찍은 뒤 마구 흔들어도 되돌아옴)
- **내보냈다 가져오면 그대로** (자동 저장 파일은 안 건드림)

검사는 진짜 저장 파일을 안 건드린다 (`SEMTLE_SAVE` 를 임시 파일로 돌려 둔다).

### 정답 그림

```
mkdir -p 정답
./semtle --answers      # 단계마다 정답 회로를 짓고 한 장씩 찍는다
```

[`정답/`](정답/) 에 30장이 들어 있다. **막혔을 때만 보는 게 낫다.**

검사(29번)와 **같은 코드**(`buildSolution`)로 짓는다 — 따로 두면 어느 한쪽이 낡아서,
정답이라고 올려놓은 게 실제로는 통과 못 하는 일이 생긴다.

화면 렌더가 안 죽는지는 `SEMTLE_SMOKE=1 SDL_VIDEODRIVER=dummy ./semtle` 로 헤드리스 확인
(네 방향으로 돌린 부품 전종, 배율 최소~최대 훑기, 복사·맞춤, 첫 화면·학습·샌드박스
세 화면, 힌트 펼친 상태, Tab 으로 판 숨긴 상태, 창 크기 최소~큼직까지 다 밟는다).
ASan/UBSan 으로도 둘 다 깨끗하다.
